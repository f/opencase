# The Silent Stable

This is a fictional teaching case. Its people, stable, horse, timeline, motive,
and outcome are invented.

The narrow story mechanic is inspired by Arthur Conan Doyle's public-domain
“Silver Blaze”: the absence of an expected guard-dog reaction can be positive
evidence that a visitor was familiar. Read the source through
[Project Gutenberg](https://www.gutenberg.org/ebooks/834).

The package drove a generic engine improvement. Its first deduction now uses a
closed value-aware proof branch: the observed monitor must report exactly zero
bark events and zero dropout, the plan must report gate coverage as `true`, and
the familiar-role array must contain `farrier`. An absent field fails closed;
observed `0` and `false` remain valid values. No case-specific `silent-stable`
rule was added to the engine.

The three raster evidence images were generated with OpenAI ImageGen for this
fictional package. They contain no material copied from the story or a real
investigation. Exact clue values stay in structured YAML reports rather than
depending on text rendered into an image.
