# Yard Switch

`yard-switch` is a fictional composite training case. No railroad, location,
crew member, train number, or event in this package represents a real person or
occurrence.

The case adapts general investigation mechanics found in official railroad
accident reporting: documenting a switch route, reconciling event-recorder and
control clocks, ordering radio/authorization events, and preserving recorder
data before it is overwritten. The facts, outcome, timings, graphics, and
responsibility chain here were invented for the demo.

Sources consulted for those mechanics:

- [NTSB Railroad Investigation Report RIR-24-12](https://www.ntsb.gov/investigations/AccidentReports/Reports/RIR2412.pdf)
- [NTSB railroad accident report catalog](https://www.ntsb.gov/investigations/AccidentReports/Pages/Reports.aspx?mode=Railroad)

This package is not a summary or simulation of RIR-24-12. Consult the official
report for the actual event and findings.

The three raster evidence images were generated with the built-in ImageGen
workflow for this fictional package. Exact switch positions and times remain
structured YAML observations rather than pixel-derived facts.
