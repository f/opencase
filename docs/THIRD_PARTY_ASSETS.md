# Third-party interface assets

The desktop and in-app interface icons come from [Lucide](https://lucide.dev/),
installed through `lucide-static`. The SVG files are bundled into the build;
the game does not hotlink them at runtime.

- Package: `lucide-static`
- Source: <https://github.com/lucide-icons/lucide>
- License: ISC
- License text: <https://github.com/lucide-icons/lucide/blob/main/LICENSE>

Case-owned photos, audio, video, and other evidence remain inside each case
package and are not part of this interface icon set.
